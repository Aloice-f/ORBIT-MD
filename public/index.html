Good to know

The session ID is a login
Whoever holds it can read and send messages as that number. Never post it in a group or a public repository. To cut it off, remove the device under Settings → Linked devices.
Nothing is stored
Pairing runs in a temporary folder that is deleted when it ends. The session ID stays in server memory for a few minutes so your browser can collect it, then it is forgotten.
Run it in one place
If the same session connects from two hosts, one of them is disconnected. Stop the old host before starting a new one.
Use a spare number if you can
This works through an unofficial WhatsApp library, and WhatsApp can restrict numbers that behave like bots.
